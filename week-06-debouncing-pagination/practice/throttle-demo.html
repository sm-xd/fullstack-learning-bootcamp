🔄 Debounce

Waits until action stops, then fires once.

Use for: Search input, resize events, form validation

⏱️ Throttle

Fires at a steady rate while action continues.

Use for: Scroll events, mouse tracking, progress updates

How Throttle Works

Notice how the regular handler fires hundreds of times as you move, while the throttled handler fires at most once every 100ms.

Throttle is perfect for events that fire rapidly but where you still want regular updates.

The Throttle Function

function throttle(func, limit) {
  let lastRun = 0;
  
  return function(...args) {
    const now = Date.now();
    
    // Only run if enough time has passed
    if (now - lastRun >= limit) {
      lastRun = now;
      func.apply(this, args);
    }
  };
}
