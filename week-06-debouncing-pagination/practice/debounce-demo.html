How Debounce Works

Notice how the regular input logs every single keystroke, while the debounced input only logs once you stop typing for 500ms.

This is crucial for search boxes where each keystroke might trigger an API call!

The Debounce Function

function debounce(func, delay) {
  let timeoutId;
  
  return function(...args) {
    // Cancel any pending execution
    clearTimeout(timeoutId);
    
    // Schedule new execution
    timeoutId = setTimeout(() => {
      func.apply(this, args);
    }, delay);
  };
}
