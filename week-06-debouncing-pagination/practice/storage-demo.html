💾 Storage Demo

Compare localStorage vs sessionStorage behavior

📦 localStorage

Persists until manually cleared (survives browser close)

No data stored

⏳ sessionStorage

Clears when tab closes (temporary storage)

No data stored

Comparison

Feature localStorage sessionStorage
Persistence Until manually cleared Until tab/window closes
Scope Shared across all tabs (same origin) Per tab/window only
Size Limit ~5-10 MB (browser dependent) ~5-10 MB (browser dependent)
Common Use Cases User preferences, auth tokens, saved data Temporary form data, session cache
💡 Tip: Both storage types only store strings. Use JSON.stringify() to save objects and JSON.parse() to retrieve them.
🧪 Try This Experiment:
  1. Save data to both storages
  2. Open this page in a new tab — localStorage data appears, sessionStorage is empty
  3. Close the tab, reopen — localStorage persists, sessionStorage is gone
  4. Close the entire browser, reopen — localStorage still persists!
